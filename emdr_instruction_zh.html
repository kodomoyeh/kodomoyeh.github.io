EMDR Lightbar 連線與操作 SOP

本裝置會建立 Wi-Fi 熱點（無對外網路）。為避免手機自動切換到其他可上網的基地台，請先把其他常用 Wi-Fi 的「自動連線」關閉（作業結束後再打開）。

快速三步驟

插入電源 (USB type C) 插入電源後，前方綠燈會閃爍六下表示啟動完成。
關閉其他 Wi-Fi 的「自動連線」，並連上 Lightbar 熱點 iOS：到 設定 → Wi-Fi → (你的家用/公司網路) ⓘ，把 自動加入 關掉。
Android：到 設定 → 網路與網際網路 / Wi-Fi → 已儲存的網路，把常用網路的 自動連線 / 自動重新連線 關掉。

接著在手機 Wi-Fi 清單選擇你的 Lightbar（例如 EMDR_XXXX），輸入密碼。看到「無網際網路」提示屬正常，請選擇 仍要保留連線。
開啟控制頁 打開瀏覽器並進入 http://192.168.4.1 建議將此ip加入我的最愛並設定為好記的名字，例如 EMDR 控制播放 。
開啟 192.168.4.1
提醒：若瀏覽器顯示「沒有網路」，仍可造訪 192.168.4.1（它是區域網路位址）。

iOS（iPhone / iPad）

  1. 到 設定 → Wi-Fi。在「我的網路」中，對其他常用基地台（家用、公司等）點選 ⓘ → 關閉 自動加入（或使用「忽略此網路」暫時移除）。
  2. 在 Wi-Fi 清單中選擇 EMDR_XXXX，輸入密碼並連線。
  3. 若出現「此網路沒有網際網路」，請點「仍要保留連線」。
  4. 打開 Safari / Chrome，輸入 192.168.4.1 進入控制介面。
進階（如有斷線/跳網）
  • 暫時關閉 設定 → 行動服務 → Wi-Fi 輔助（如你的機型有此選項）。
  • 若系統自動彈出登入頁（Captive Portal）卻空白，請直接開瀏覽器手動輸入 192.168.4.1。

Android（各品牌）

  1. 到 設定 → 網路與網際網路 / 連線 → Wi-Fi → 已儲存/已知的網路，將其他常用基地台的 自動連線 / 自動重新連線 關閉（或按「忘記」暫時移除）。
  2. 在 Wi-Fi 清單選擇 EMDR_XXXX，輸入密碼並連線。
  3. 若系統提示「沒有網際網路」，請選擇「仍保留 / 保持連線」。
  4. 打開瀏覽器，輸入 192.168.4.1 進入控制介面。
進階（品牌差異設定）
  • Samsung：Wi-Fi → 右上角 ⋮ → 進階 → 關閉「切換到行動數據 / 智慧網路切換」。
  • Pixel / 原生：Wi-Fi → 網路偏好設定 → 關閉「自動切換到行動數據 / 切換到更佳網路」。
  • MIUI / 其他：尋找 Wi-Fi 助手 / 網路輔助 類似選項並關閉。

在控制頁上操作

  • 調整 Speed（BPM）、選擇 Color、設定 Move Mode 與 Move Count。
  • 先按 Set up 套用設定，再按 Start / Stop 控制播放。
  • 光點移動中仍然可更改設定，同樣需要按下 Set up 才會套用設定。

常見問題（Troubleshooting）

無法開啟 192.168.4.1
  • 確認仍連到 Lightbar 熱點，且未被手機自動切到其他基地台。
  • 若瀏覽器一直嘗試上網，可暫時關閉 行動數據 再試一次。
  • 重新連線 Wi-Fi 後，手動輸入完整網址：http://192.168.4.1。
可以使用行動電源嗎?
  • 可以的。測試使用 5000mAh 行動電源，一小時約掉 3%。
為什麼光點跑了一格就不動了？
  • 舊版的 FW 可能在使用 Move count 之後會有這個問題，新版的已解決此問題
  • 這類的板子建議在想要 Start 的時候 先按一次 [Set up] 再 按 [Start / Stop]。
舊版的 FW 可以升級嗎？
  • 升級 FW 需要將 lightbar 寄回原廠才有辦法升級，目前無法遠端升級。
