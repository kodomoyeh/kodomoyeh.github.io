EMDR Lightbar Connection & Operation SOP

This device creates a Wi-Fi hotspot (no Internet access). To prevent your phone from automatically switching to other networks with Internet, please temporarily disable “Auto-Join” (or similar) on your usual Wi-Fi networks (you can re-enable after use).

Quick 3 Steps

Disable Auto-Join on other Wi-Fi
iOS: Go to Settings → Wi-Fi → (your home/office network) ⓘ, turn off Auto-Join.
Android: Go to Settings → Network & Internet / Wi-Fi → Saved Networks, disable Auto-connect / Auto-reconnect on common networks.
Connect to the Lightbar hotspot On your phone’s Wi-Fi list, select your Lightbar (e.g. EMDR_XXXX) and enter the password. Seeing “No Internet” is normal — choose Keep using this Wi-Fi.
Open the control page Open your browser and go to http://192.168.4.1. It is recommended to bookmark this IP and name it something easy to remember, e.g. EMDR Control.
Open 192.168.4.1
Note: If the browser shows “No Internet”, you can still access 192.168.4.1 (it is a local network address).

iOS (iPhone / iPad)

  1. Go to Settings → Wi-Fi. For other usual networks (home, office, etc.), tap ⓘ → turn off Auto-Join (or “Forget This Network” temporarily).
  2. Select EMDR_XXXX from the Wi-Fi list, enter the password and connect.
  3. If “No Internet” appears, tap Keep Using This Network.
  4. Open Safari / Chrome, enter 192.168.4.1 to access the control page.
Advanced (if disconnecting / auto-switching)
  • Temporarily disable Settings → Cellular → Wi-Fi Assist (if available on your model).
  • If a captive portal login page appears blank, manually open the browser and type 192.168.4.1.

Android (various brands)

  1. Go to Settings → Network & Internet / Connections → Wi-Fi → Saved/Known Networks. Disable Auto-connect / Auto-reconnect on other usual networks (or “Forget” temporarily).
  2. Select EMDR_XXXX in the Wi-Fi list, enter the password and connect.
  3. If you see “No Internet”, choose Keep Connected / Stay Connected.
  4. Open the browser and enter 192.168.4.1 to access the control page.
Advanced (brand-specific settings)
  • Samsung: Wi-Fi → top-right ⋮ → Advanced → disable “Switch to mobile data / Smart Network Switch”.
  • Pixel / Stock Android: Wi-Fi → Network preferences → disable “Auto-switch to mobile data / Switch to better network”.
  • MIUI / Others: Look for Wi-Fi Assistant / Network Assist and disable.

Operating the Control Page

  • Adjust Speed (BPM), select Color, set Move Mode and Move Count.
  • Press Set up to apply settings, then Start / Stop to control playback.
  • You can modify settings while the light is moving — remember to press Set up again to apply changes.

Troubleshooting

Cannot open 192.168.4.1
  • Check that you are still connected to the Lightbar hotspot and not switched to another network.
  • If the browser keeps trying to use Internet, temporarily turn off Mobile Data and try again.
  • Reconnect Wi-Fi and manually enter the full address: http://192.168.4.1.
Frequent disconnects / unstable speed
  • Stay within 1–3 meters of the device with minimal obstacles.
  • Avoid power-saving mode; keep your screen awake.
What to do after finishing?
  • Go back to Settings and re-enable Auto-Join/Auto-connect on your usual Wi-Fi networks.
  • Reconnect to your normal Wi-Fi or mobile data.
This guide applies only to Lightbar local connection usage; it is normal that the device does not provide Internet access. ©
